# Noto Sans Lao Looped

Source: Google Fonts official repository, `ofl/notosanslaolooped/NotoSansLaoLooped[wdth,wght].ttf`.
Downloaded 2026-10-11. Upstream family: Noto Sans Lao Looped, release 1.002.
https://github.com/google/fonts/tree/main/ofl/notosanslaolooped

The TTF is the upstream variable font. The WOFF2 is a lossless web-font conversion using fontTools, without subsetting or changing glyphs. Weight range: 100–900; normal width retained. License: SIL Open Font License 1.1, see OFL.txt.

The app uses the private CSS family name `Lao Looped App`. Its unicode-range only covers Lao letters/marks (U+0E80–0ECF, U+0EDC–0EFF), deliberately excluding Lao digits U+0ED0–0ED9 as well as all Latin, Chinese, ASCII digits and IPA. Original fallback stacks remain intact. No remote font request is made.

Scanned rendering paths: dictionary, search, detail dialogs, alphabet, practice, learning modules, pronunciation/coda maps and tables, form controls and dynamically generated HTML. All are regular DOM inheriting the body or the three explicit Lao font stacks. SVG is only used for non-text player icons; textbook screenshots are images and cannot be re-fonted by CSS.
